# 语言支持

[English](en/LOCALIZATION.md) · **简体中文** · [文档中心](README.md)

| 内容 | 当前提供的语言 |
|---|---|
| README、安装、上手、兼容性与排障文档 | 简体中文、英文 |
| 隐私、安全、支持与更新说明 | 简体中文、英文 |
| 问题反馈 | 中文和英文表单；功能建议支持双语填写 |
| 安装器、诊断工具、CLI 帮助和提示 | 当前为英文 |

每页顶部可以切换到另一语言的对应页面。命令名、参数、JSON 字段、环境变量和错误码在不同语言中保持一致；请勿翻译后再执行。

文档语言不会改变 NAS 文件名、文件内容或服务返回数据的语言，也不会改变 Agent 所使用模型的语言能力。Agent skills 使用同一套命令说明，不需要按语言重复安装。

发现翻译错误或需要其他语言，可通过[支持渠道](../SUPPORT.zh-CN.md)提交页面地址和建议，避免附带私人文件内容。
