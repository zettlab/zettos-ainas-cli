# 多语言范围与维护规范

[English](en/LOCALIZATION.md) · **简体中文** · [文档中心](README.md)

首批文档语言为 `en`（英文）和 `zh-CN`（简体中文）。其他语言尚未交付；新增语言应明确维护者和复核方式，不能把仅翻译标题计为支持。

| 层次 | 当前状态 | 完成标准 |
|---|---|---|
| README 与用户文档 | 中英文成对提供 | 从首页到安装、登录、排障、支持不必切换语言；已知限制一致 |
| 隐私、安全、支持、更新记录 | 中英文成对提供 | 数据流、凭据清理、报告渠道、支持边界一致 |
| 问题反馈 | 中英文问题表单、双语功能建议 | 用户能够用所选语言完成提单 |
| 安装器与诊断工具 | 当前英文 | 待实现显式语言选择、系统语言识别、英文回退与全错误路径验证 |
| CLI 帮助、错误和确认提示 | 当前英文 | 待统一消息标识与资源目录；翻译不改变命令/API/JSON 契约 |
| Agent skills | 保持当前生成内容 | 尚未进行按语言拆分和双语用户场景验收；不重复安装同名 skills |
| 法律许可 | LICENSE / TOOLING-LICENSE 英文正文 | 本次没有修改许可文本；说明文档的翻译不新增或替代授权 |

## 文件组织

- `README.md`：英文首页；`README.zh-CN.md`：中文首页。
- `docs/en/*.md`：英文指南；现有 `docs/*.md`：中文指南，保留已有链接。
- `SUPPORT.md` / `SUPPORT.zh-CN.md`、`CONTRIBUTING.md` / `CONTRIBUTING.zh-CN.md`：成对入口。
- 中文 `PRIVACY.md`、`SECURITY.md`、`CHANGELOG.md` 保留现有地址；英文在 `docs/en/`。
- 每页顶部提供另一语言的对应页和文档导航。

## 翻译规则

命令名、flag、JSON 字段、环境变量、版本、路径、错误码和 API 名称不得翻译。自然语言搜索示例可以本地化，但权限、确认要求和行为必须一致。保留占位符，不引入真实账号、设备地址或私有文件名。

用词统一：skill 为 Agent 使用说明，不是独立 NAS 应用；`search` 为查找，`ask` 为问答上下文检索，最终自然语言回答由 Agent/模型生成；“支持”“已验证”“实验性”“计划支持”不得混用。

修改产品事实时同步更新对应语言；检查相对链接、示例参数、当前版本、风险提示和限制。新增页面需加入两种语言的文档索引。尚未完成的翻译要明确标注并链接可用原文，不得用静默英文跳转冒充完整翻译。

当前尚无自动化翻译缺失/过期门禁。维护者需在 PR 中完成配对审查；自动化门禁和母语复核列为后续发布质量工作。新增语言以完整任务路径为单位验收，不按文件数量宣布完成。
