# 商业发布准备度

[English](en/READINESS.md) · **简体中文** · [文档中心](README.md)

当前项目属于发行基础设施与产品验收建设阶段，**尚不满足商业就绪声明**。以下以能证明结果的验收条件评估，不用 README 数量、接口数量或单次 CI 绿灯代替用户体验。

| 维度 | 已有基础 | 仍缺的交付与验收 |
|---|---|---|
| 产品定位与信息架构 | 双语首页、任务入口、统一文档中心 | 经真实新用户验证的首次使用路径；真实演示素材与清晰成功标准 |
| 多语言 | 中英文完整文档路径与反馈表单 | 安装器/CLI 消息本地化、语言回退、翻译过期门禁、母语复核；见多语言规范 |
| 安装与版本生命周期 | 签名下载、版本目录、恢复、回退、卸载 | 正式公开下载后的匿名安装；真实发布版本间升级；Mac 签名/公证决策与验收 |
| 核心业务可靠性 | Linux 两平台原生验证；NAS 登录与部分读取 | 有存储和测试内容的 NAS 浏览/搜索/问答；权限、会话失效、可逆写入和清理；后端刷新问题闭环 |
| 兼容性与可维护性 | 平台/固件矩阵与实际证据 | Mac 与最低系统边界验证；支持固件范围、淘汰策略和回归设备清单 |
| 安全与供应链 | 凭据保护、显式危险操作确认、签名、依赖审查、私密报告 | 密钥备份/轮换演练、修复责任人与支持期限；持续漏洞门禁、发布物溯源与恢复演练 |
| 诊断与支持 | 本地最小诊断、双语表单、支持与安全分流 | 稳定错误分类、可操作的恢复指引；经验证的脱敏报告；分级、负责人及响应政策 |
| 发布工程与质量治理 | 私有源码/公开发行分离、三平台工具 CI、Linux 附件验收 | 全平台完整门禁、签名清单与标签一致性、版本文档同步、发布撤回和回退演练 |
| 许可、隐私与运营 | 二进制/工具授权区分、第三方材料、数据流说明 | 发布方确认授权与隐私文案、明确支持承诺、维护责任人；不编造 SLA 或认证 |

## 按交付结果分批推进

1. **文档与语言入口**：本批补齐中英文路径、支持、贡献、反馈表单和缺口记录；检查链接、命令和两种语言的事实一致性。
2. **产品多语言与首次体验**：统一安装器/CLI 提示资源，提供语言选择与回退；保持机器可读输出稳定；用真实新用户走通安装到第一次成功浏览。
3. **阻断性验收**：补齐 Mac，使用准备好的 NAS 完成核心场景，解决长期登录问题；在此前保留草稿状态。
4. **可持续交付**：建立翻译同步、发布证据、兼容性回归、维护责任与版本支持规则；通过真实升级/故障恢复演练后再宣布对应能力达标。

具体验收证据以 [ACCEPTANCE.md](ACCEPTANCE.md) 为准。当前最直接的外部条件是可用的 Apple Silicon Mac、已有存储和测试文件的 NAS，以及后端刷新令牌问题的处理。文档工作可以先推进，但不能把这些条件标成已完成。
