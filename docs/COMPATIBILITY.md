# 兼容性与支持范围

这是首个公开 Beta 的验收范围。**编译成功、接口存在、文档覆盖都不等于已通过实机验证。** 发布附件与实际通过的平台以 Release 验收记录为准。

| 客户端平台 | 计划附件 | 当前状态 |
|---|---|---|
| Linux x86_64 | `znas-linux-x86_64.tar.gz` | 签名候选包在 Ubuntu 24.04 原生验证通过；glibc 符号要求 2.34，更低系统版本未验证 |
| Linux ARM64 | `znas-linux-aarch64.tar.gz` | 签名候选包在 Ubuntu 24.04 ARM64 原生验证通过；更低系统版本未验证 |
| macOS Apple Silicon | `znas-macos-aarch64.tar.gz` | 构建、最低系统版本、签名和运行待验证 |
| Windows / Intel Mac | 无 | 暂不支持，不承诺 WSL 或 Rosetta 兼容性 |

NAS 固件兼容性必须通过真实设备记录。Zettlab D6 Ultra / ZettOS `1.14.0-beta` 已通过登录和设备、固件、存储读取；该测试环境没有存储池，文件、搜索、问答未通过，且刷新令牌仅有效 1 秒，长期保持登录尚未验证。详见 [ACCEPTANCE.md](ACCEPTANCE.md)。当前不声明“支持全部 ZettOS 版本”，也不把内部服务源码分支号当成用户固件版本；不公开设备序列号、IP 或个人用户名。

| 能力 | 前置条件 | 首发验证要求 |
|---|---|---|
| 登录、文件浏览 | 可达网关、已有 NAS 用户和存储空间 | 必测：登录、token 刷新、过期、普通用户权限 |
| 搜索、问答 | 文件权限；AI 模型、服务及索引准备好 | 必测：普通搜索、AI 不可用时的行为、问答 |
| 设置与桌面状态 | 对应服务；部分操作需要管理员 | 必测读取；写入按风险分级独立验证 |
| 应用、容器 | NAS 已具备对应服务和可用存储池 | 实验性，安装/启动/清理需完成场景验收 |
| 照片 | 照片应用和索引 | 实验性，需补正式用户场景 |
| Coder、Theater | 已安装对应应用、可用网关路由 | 实验性，需补正式用户场景 |
| 外网连接 | 官方配置完成且网关 HTTPS 可达 | 不假设所有远程模式可用，逐模式验收 |

出现 `404`、服务不可达或权限不足时，先确认固件和应用版本。CLI 不会通过主机原生命令替代 NAS 控制 API。Linux 二进制若要求的 glibc 高于系统版本，安装预检会失败并保留原版；不要替换系统 glibc 来安装 CLI。
