# Language support

**English** · [简体中文](../LOCALIZATION.md) · [Documentation](README.md)

| Content | Available languages |
|---|---|
| README, installation, quick start, compatibility, troubleshooting | English and Simplified Chinese |
| Privacy, security, support, changelog | English and Simplified Chinese |
| Issue reporting | English and Chinese forms; bilingual feature requests |
| Installer, diagnostics, CLI help and messages | Currently English |

Use the link at the top of each page to switch to its counterpart. Command names, flags, JSON keys, environment variables, and error codes stay the same across languages. Do not translate them before execution.

Documentation language does not change NAS filenames, content, service responses, or the language capabilities of your agent's model. Agent skills share one command reference and do not need separate installations for each language.

To report a translation problem or request another language, use [support](../../SUPPORT.md) with the page URL and suggested change. Do not attach private content.

The license texts are [LICENSE](../../LICENSE) and [TOOLING-LICENSE](../../TOOLING-LICENSE). Translated explanations do not replace those texts.
